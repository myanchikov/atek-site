# Сайт A·TEK на Tilda + Google Таблица

Сайт — на Tilda. Товары, цены, остатки и новости — в Google Таблице.
Меняете ячейку в таблице → через несколько секунд это видно на сайте. Перепубликовывать страницы в Tilda не нужно.

```
Google Таблица ──> Apps Script (JSON-API) ──> блоки T123 на страницах Tilda
        ^                                           │
        └──── заявки и оптовые запросы ─────────────┘   (оплата — корзиной Tilda ST100)
```

**Нужен платный тариф Tilda** (Personal или Business): без него не работают блоки T123 и код в `<head>`.

## Что в папке

| Файл | Куда |
|---|---|
| `apps-script/Code.gs` | Google Таблица → Расширения → Apps Script |
| `tilda/00-head.html` | Tilda → Настройки сайта → Ещё → HTML-код для вставки внутрь head |
| `tilda/atek.css`, `tilda/atek.js` | стили и движок блоков (подключаются из head) |
| `tilda/01-header.html`, `02-footer.html` | T123 на страницах «Шапка» и «Подвал» |
| `tilda/10-home.html` | главная (6 секций, каждую — отдельным T123) |
| `tilda/20-catalog.html` | страница `/catalog` |
| `tilda/30-product.html` | страница `/product` (шаблон карточки товара) |
| `tilda/40-news.html`, `41-news-item.html` | страницы `/news` и `/news-item` |
| `preview/index.html` | превью всех страниц на тестовых данных |

## 1. Таблица и API (15 минут)

1. Создайте пустую Google Таблицу, например «A·TEK — сайт».
2. **Расширения → Apps Script**. Удалите всё в `Код.gs`, вставьте содержимое `apps-script/Code.gs`, сохраните.
3. Вверху выберите функцию `setup` → **Выполнить** → разрешите доступ.
   Появятся листы *Товары, Категории, Новости, Настройки, Заявки, Импорт, Журнал* с тестовыми данными и меню **A·TEK**.
4. **Развертывание → Новое развертывание → Веб-приложение**:
   запуск от имени — *Я*, доступ — *Все*. Скопируйте URL вида `https://script.google.com/macros/s/…/exec`.
5. Откройте этот URL в браузере — должен показаться JSON с товарами.
6. Лист **Настройки**: в `email` впишите почту, куда присылать заявки. Там же телефон, валюта, порог «Мало».

> После изменения кода скрипта: Развертывание → Управление → карандаш → Версия «Новая». URL останется прежним.

## 2. Tilda (30 минут)

1. **Подключите стили и движок.** Удобнее всего через GitHub:
   создайте публичный репозиторий `atek-site`, загрузите папку `tilda/`. В `00-head.html` замените `ВАШ_GITHUB` на ваш логин.
   После правок файлов сбрасывайте кэш: откройте `https://purge.jsdelivr.net/gh/ВАШ_GITHUB/atek-site@main/tilda/atek.js`.
   *Без GitHub:* вставьте содержимое `atek.css` в `<style>`, а `atek.js` в `<script>` прямо в head (или в T123 на странице «Шапка»).
2. Вставьте `00-head.html` в **Настройки сайта → Ещё → HTML-код для вставки внутрь head**, подставьте URL из шага 1.4 в `api`.
3. **Шапка и подвал:** создайте страницы «Шапка» и «Подвал», в каждую — T123 с кодом `01-header.html` / `02-footer.html`.
   Настройки сайта → Шапка и подвал → выберите эти страницы.
4. **Страницы:** создайте `/` (главная), `/catalog`, `/product`, `/news`, `/news-item` (адрес — в Настройках страницы).
   В каждую — блок T123 (Другое → HTML-код) с кодом из соответствующего файла.
5. **Фон страниц:** Настройки страницы → Цвет фона `#1A1C20` (или для всего сайта в Настройках сайта).
6. **Корзина и оплата:** добавьте штатный блок **ST100** (Магазин → Корзина) на каталог, товар и главную
   (или на «Шапку» — тогда он везде). Платёжную систему и доставку настройте в Настройках сайта → Платёжные системы.
   Кнопки «В корзину» кладут товар в эту корзину. Если ST100 на странице нет — вместо корзины открывается форма заказа.
7. Опубликуйте. Проверьте: каталог показывает товары, «В корзину» работает, тестовая заявка пришла на почту и в лист «Заявки».

## 3. Как вести товары (лист «Товары»)

| Колонка | Что писать |
|---|---|
| `sku` | Артикул, уникальный. По нему работает всё: ссылки, импорт цен |
| `active` | `1` — показывать, `0` — скрыть с сайта |
| `line` | `vision`, `access`, `smart` или `fix` |
| `category` | `id` из листа «Категории» |
| `price`, `price_old` | Цена и старая цена (если есть — появится скидка −N%) |
| `stock` | Остаток. `0` → «Под заказ» и кнопка «Запросить срок поставки» |
| `difficulty` | Уровень монтажа `1`, `2`, `3` — как на упаковке (01 простой / 02 навыки / 03 специалист) |
| `series` | `PRO` для профессиональной серии |
| `image`, `gallery` | Ссылки на фото. Подходит ссылка «Поделиться» из Google Диска (доступ «Все, у кого есть ссылка») или ссылка на файл, загруженный в Tilda. `gallery` — несколько через запятую |
| `short` | Одна строка под названием, она же meta description |
| `description` | Описание. Пустая строка = новый абзац, `**жирный**`, `[текст](ссылка)`, строки с `- ` = список |
| `specs` | Характеристики, каждая с новой строки: `Разрешение: 4 Мп` |
| `docs` | Документы, каждый с новой строки: `Паспорт | https://…/passport.pdf` |
| `sort` | Порядок в каталоге (меньше — выше) |
| `page_url` | Если у товара своя страница в Tilda (см. п. 5) |

Новости — лист «Новости»: `id` (латиницей, попадёт в ссылку), `published` (1/0), `date` (ГГГГ-ММ-ДД), `title`, `tag`, `cover`, `excerpt`, `body` (та же разметка, картинка — строка `![](ссылка)`).

## 4. Обновление цен и остатков

- **Руками:** правите ячейки в «Товарах» — сайт обновится при следующем открытии страницы (кэш сбрасывается автоматически).
- **Пачкой:** вставьте в лист «Импорт» колонки `sku | price | stock | price_old` (выгрузка из 1С, МойСклад, прайса поставщика) →
  меню **A·TEK → Импорт цен/остатков из листа «Импорт»**. Пустые ячейки не трогаются, лист очищается, итог — во всплывающем окне.
- **Автоматически:** положите в Настройки `feed_url` — ссылку на CSV с колонками `sku;price;stock`
  (например, опубликованная как CSV другая таблица или выгрузка со склада). Скрипт забирает его раз в час.
- Все изменения пишутся в лист **«Журнал»**: когда, что, было → стало.
- Не видно изменений? Меню **A·TEK → Обновить сайт сейчас**, затем обновите страницу.

## 5. Как «размножить» карточку товара

**Способ 1 — ничего не размножать.** Одна страница `/product` показывает любой товар: `/product?sku=VIS-B2-28`.
Каталог сам строит такие ссылки. Новый товар = новая строка в таблице.

**Способ 2 — отдельные страницы (лучше для SEO).** Для ключевых товаров:
Tilda → дублировать страницу `/product` → адрес `/vision-b2-28`, свой Title и Description в настройках страницы →
в блоке впишите `data-sku="VIS-B2-28"` → в таблице в `page_url` этого товара `/vision-b2-28`.
Цена и остаток всё равно берутся из таблицы.

Про поисковики: содержимое рисуется скриптом. Google такое индексирует, Яндекс — не всегда. Поэтому для товаров,
по которым важен трафик из Яндекса, используйте способ 2 и заполняйте Title/Description в Tilda.

## 6. Полезные настройки блоков

- Каталог одной линейки: `<div data-atek="catalog" data-line="vision"></div>`
- Ссылка с фильтром: `/catalog?line=access&cat=locks&stock=1&pro=1&lvl=1`
- Подборка на любой странице: `<div data-atek="featured" data-skus="VIS-B2-28,ACC-KP-01"></div>` или `data-line="smart" data-limit="4"`
- Последние новости: `<div data-atek="news" data-limit="3" data-filters="0"></div>`
- Любая кнопка открывает форму заявки: `<button data-atek-request="opt" data-title="Оптовый прайс">…</button>`
- Цель в Метрике при отправке заявки: укажите `ymId` в head, цель — JavaScript-событие `atek_lead`.

## 7. Логотип и шрифт

В шапке и подвале логотип нарисован в SVG по концепции. Когда будет финальный файл от дизайнера —
замените содержимое `<a class="atek-logo">…</a>` на свой SVG (цвет букв `currentColor`, точка `#F47735`).
Шрифт — Onest (Google Fonts, с кириллицей), близок к гротеску из концепции.

## Ограничения

- Google Apps Script: бесплатно, но первый запрос после правки таблицы идёт 1–2 с, дальше — из кэша.
  Комфортно до ~2 000 товаров; больше — стоит разделить выдачу или перейти на отдельный сервер.
- Функции корзины Tilda (`tcart__addProduct`) официально не документированы; если Tilda их поменяет,
  кнопка автоматически переключится на штатную ссылку `#order`, а без корзины — на форму заказа.
